# LeetCode Playground

A Claude Code plugin for practicing LeetCode problems interactively.

## Features

- Show problem description, constraints, and examples by number
- Create solution files in 11+ languages with the correct function skeleton
- Validate with compilation checks and 30+ auto-generated test cases (edge cases, stress tests, performance tests)
- Track multiple attempts per problem

## Installation

```
/install leetcode-playground@leetcode-playground
```

Or browse in `/plugin > Discover` after adding this marketplace.

## Usage

```
/leetcode-playground 42
```

or just say "leetcode 121", "solve problem 1", "practice two sum", etc.

## Supported Languages

C++, Java, Python, Go, Rust, JavaScript, TypeScript, C, C#, Kotlin, Swift
